# Calculadora de Juros

Programa em JavaScript (Node.js) que calcula juros de uma dívida
com base nos dias de atraso.

## Regra
- Mais de 15 dias de atraso: juros de 10%
- Até 15 dias: juros de 5%

## Como rodar
node juros.js

## Conceitos praticados
Variáveis, operadores, tipos de dados, input e estruturas condicionais.
